# Assets Requis pour le Niveau 2 (TEST BETA) - Thème Spatial

*Note : Le thème du jeu se déroule dans un laboratoire secret en orbite / station spatiale. L'esthétique doit être sci-fi, futuriste, avec des éléments cosmiques.*

Voici la liste des assets dont nous aurons besoin pour le Niveau 2, sous forme de "Prompts" prêts à être copiés/collés dans un générateur d'images IA (comme Midjourney, DALL-E 3, etc.).

---

## 1. La Carte du Niveau (Background / Labyrinthe)

Le niveau 2 est maintenant un labyrinthe où le joueur doit collecter des données tout en étant poursuivi. Nous avons besoin d'une vue de dessus (top-down) d'un labyrinthe spatial.

**Nom de l'asset :** `level2_maze.png`

**Prompt IA :**
> `Top-down 2D game background asset, a sci-fi laboratory maze inside a space station. Metallic walls forming a labyrinth, dark glowing neon blue floor lines, futuristic panels. High-tech, dark and moody atmosphere, cyberpunk lighting, clean digital art, perfect for a 2D top-down indie game, high resolution, top-down perspective --ar 16:9`

---

## 2. La Porte de Sortie (Door)

La porte par laquelle le robot RTB-O9 doit s'enfuir une fois les 5 fragments collectés. Il en faut une version fermée et une version ouverte.

**Nom de l'asset :** `door_closed.png` et `door_open.png`

**Prompt IA (Porte fermée) :**
> `2D game asset, top-down view of a futuristic sci-fi blast door, closed. Heavy metallic texture, warning stripes, glowing red lock indicator in the center. Industrial space station aesthetic, clean digital art, transparent background, isolated object, vector style game art`

**Prompt IA (Porte ouverte) :**
> `2D game asset, top-down view of a futuristic sci-fi blast door, fully open, revealing a glowing blue energy hallway underneath. Industrial space station aesthetic, clean digital art, transparent background, isolated object, vector style game art`

---

## 3. Les Fragments de Données (Collectibles)

Les objets lumineux que le joueur doit ramasser dans le labyrinthe.

**Nom de l'asset :** `data_fragment.png`

**Prompt IA :**
> `2D game asset, top-down view of a glowing holographic data cube. Neon cyan and purple colors, floating high-tech computer chip or hard drive. Cyberpunk sci-fi style, space station laboratory prop. Clean digital art, isolated on a white background, flat lighting, vector style, shiny and attractive`

---

## 4. L'Ennemi : Le Robot Nettoyeur (The Chaser)

Le robot imposant et invincible qui poursuit le joueur à travers le labyrinthe. Il doit avoir l'air lourd et menaçant.

**Nom de l'asset :** `cleaner_robot.png`

**Prompt IA :**
> `2D game asset, top-down view of a heavy, bulky sci-fi cleaner robot. Industrial yellow and black hazard stripes, glowing angry red sensors. Looks like a futuristic bulldozer or heavy security drone. Space station aesthetic, clean digital art, transparent background, isolated object, symmetrical, vector style game art`

---

## 5. UI : L'Indicateur de Batterie

Selon l'histoire, *"Votre batterie est votre vie, si elle atteint 0%, vous mourrez."* Pour rendre l'interface plus immersive dans le thème spatial.

**Nom de l'asset :** `battery_frame.png`

**Prompt IA :**
> `2D game UI asset, an empty futuristic battery frame outline. High-tech UI element, glowing neon cyan borders, sci-fi HUD design, transparent inside to act as a health bar container. Clean vector art, sleek and modern, dark space theme, isolated on black background`

---

## 6. Le Robot RTB-O9 (Le Joueur)

Bien que vous ayez déjà un asset pour le premier niveau, voici un prompt spécifique pour générer une vue de dessus (top-down) très détaillée de notre héros robotique RTB-O9.

**Nom de l'asset :** `robot_rtb_o9.png`

**Prompt IA :**
> `2D game asset, perfect top-down view of a futuristic sci-fi robot named RTB-O9. Sleek metallic white and dark grey armor panels, glowing neon blue optics and details. A visible glowing battery core on its back. High-tech space station aesthetic, clean digital art, transparent background, isolated object, symmetrical, vector style game art`
